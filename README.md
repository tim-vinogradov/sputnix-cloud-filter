# Отсев облачных спутниковых снимков

Нейросеть, которая оценивает облачность на обзорных снимках группировки СПУТНИКС и удаляет снимки, где облаков больше 75 %, вместе с парным KML-файлом. После обработки оператор получает отчет. Решение кейса СПУТНИКС (сентябрь 2026).

## Как работает

Сеть U-Net с энкодером ResNet-18 считает для каждого пикселя вероятность облака. Облачность снимка равна доле облачных пикселей среди пикселей Земли, черный космос у горизонта не учитывается.

Разметка была грубой. Для 147 снимков вручную указана доля облаков в каждой из 12 ячеек сетки 4 на 3, без точных контуров. Поэтому сеть учится на слабой разметке и сама находит, где именно в ячейке лежат облака.

## Точность

На перекрестной проверке из 5 частей средняя ошибка оценки облачности составила 6,8 процентного пункта. Решение «удалить или оставить» верно для 139 снимков из 147. Чаще всего модель ошибается на снимках с облачностью около порога и на полярных сценах, где лед похож на облака.

Модель работает на обычном процессоре, около полсекунды на снимок.

## Запуск

```
pip install -r requirements.txt
python cloud_filter.py --input папка_со_снимками --dry-run
```

С ключом `--dry-run` программа ничего не удаляет и только выдает отчет. Другие параметры: `--threshold` задает порог облачности, `--masks` сохраняет снимки с подсвеченными облаками, `--gui` показывает итог в отдельном окне.

Снимки в репозиторий не входят. Скрипт `get_images.py` скачивает их из открытого архива СПУТНИКС. Обученные веса лежат в `weights/cloudnet.pt`.

Обучение заново и перекрестная проверка:

```
python get_images.py
python train.py --epochs 40 --out weights/cloudnet.pt
python train.py --cv 5 --epochs 30
```
